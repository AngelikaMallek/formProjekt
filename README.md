## Description

This is a simple **TODO application** created as a student project for a JavaScript client-side course.  
The app allows users to manage a list of tasks with creation date, status, and optional description.

The project demonstrates:
- CRUD operations (Create, Read, Update, Delete)
- form validation based on exceptions
- DOM manipulation without frameworks
- usage of the native HTML `<dialog>` element for task details and editing

## Features
- Add new tasks with title and optional description
- Automatic task ID and creation date
- Toggle task status (`todo` / `done`)
- Edit existing tasks in a dialog
- Delete tasks from the list
- Display task details in a modal dialog
- Filter tasks (show only TO-DO tasks)
- Form validation with user-friendly error messages
